#### About the Bagfiles
There are 3 ROS bag files in this folder. The demo_bag.db3 file is a recording of our particle filter in action. It can be visualized using rviz2, and uses the test_rviz_map_save .yaml and .pgm map in the maps folder of this repository.

The macfirst_floor bag files represent data from the robot roaming through larger maps that can be used for testing the particle filter, instead of a simulator like Gazebo or an actual physical robot.
