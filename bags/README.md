#### About the Bagfiles
There are 3 ROS bag files in this folder. The demo_bag file is a recording of our particle filter in action. It can be visualized using rviz2, and uses the test_rviz_map_save map in the maps folder of this repository.   
The mac_first_floor bag files are for testing purposes, and represent data from the robot roaming through larger maps that can be used for testing the particle filter, instead of a simulator like Gazebo or an actual physical robot.
